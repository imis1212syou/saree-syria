سعرلي سوريا — Modular Project
ترتيب التحميل
index.html → core.js → app.js (المنطق الأصلي غير المكرر) → stores.js (الميزات الموسعة للمتاجر/الشركات/المواد/التجار/الإدارة) → باقي الوحدات المستقلة → traders.js (توثيق التاجر) → barcode.js → bootstrap.js
مبدأ الدمج
لا يتم تعريف الدوال الأصلية نفسها مرتين.
app.js مأخوذ من JavaScript الأصلي مع إزالة الوظائف التي لها نسخة موسعة في stores.js.
stores.js محفوظ كنسخة الميزات الموسعة الموجودة في المشروع.
الوحدات الصغيرة الأخرى لا تستبدل الدوال الأصلية، بل تمنع التعارض وتثبت بنية المشروع.
توثيق التاجر يحتاج إضافة profiles.verified عبر ملف SQL.
ملاحظة مهمة
هذه الحزمة تحافظ على منطق المشروع الحالي، لكن اختبار Supabase الفعلي يحتاج تشغيل المشروع على مشروع Supabase نفسه.
