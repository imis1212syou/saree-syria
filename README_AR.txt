تحديث تحديد الموقع — دعم Chrome 144+

الملفات:
- index.html
- store_features.js

ما تغير:
- في Chrome 144+ يستخدم زر تحديد الموقع عنصر HTML <geolocation> الرسمي، الذي يتيح للمتصفح معالجة طلب الموقع من نقرة المستخدم ويقدم مسار استعادة خاصًا عندما يكون إذن الموقع محظورًا سابقًا.
- في المتصفحات التي لا تدعم العنصر، يبقى الزر الاحتياطي ويستخدم Geolocation API المعتاد.
- عند الحصول على الإحداثيات، تُمرر إلى منطق المتاجر القريبة الموجود دون تغيير البيانات أو الخريطة اليدوية.
- تستمر معالجة الخطأ وإعادة المحاولة دون حفظ رفض الإذن داخل سعري سوريا.

التركيب:
1. خذ نسخة احتياطية من الملفين الحاليين.
2. استبدل index.html وstore_features.js في جذر مستودع GitHub Pages بهذين الملفين.
3. ارفع commit جديدًا وانتظر نشر GitHub Pages، ثم أعد فتح الموقع أو حدّثه تحديثًا قويًا.

مهم:
عنصر <geolocation> في Chrome 144+ يعالج إذن مشاركة موقعك مع الموقع، خصوصًا حالة الحظر السابق. لا يستطيع تشغيل مفتاح GPS في إعدادات أندرويد بنفسه، ولا يضمن إظهار نافذة النظام التي تظهر في Google Maps عند إيقاف خدمات الموقع. كما أن الواجهة المرئية للعنصر يتحكم بها المتصفح وقد تختلف عن زر HTML العادي. لم أتمكن من اختبار هذا الملف على جهاز Android/Chrome 144 فعلي؛ راجعت الكود وصياغته فقط.
