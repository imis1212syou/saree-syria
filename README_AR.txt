تحديث تحديد الموقع لموقع سعري سوريا

الملفات المعدّلة فقط:
- store_features.js: يبدأ طلب الموقع مباشرة عند ضغط المستخدم، ويعالج رفض الإذن وتعذر الموقع والمهلة برسائل مختلفة، ويتيح إعادة المحاولة أو اختيار الموقع على الخريطة. لا يخزّن رفض الإذن داخل الموقع.
- index.html: تحديث رقم نسخة ملف JavaScript لتقليل احتمال بقاء النسخة القديمة في ذاكرة المتصفح.

طريقة التركيب:
1. احتفظ بنسخة احتياطية من الملفين الحاليين في مستودع GitHub Pages.
2. انسخ index.html وstore_features.js من هذه الحزمة إلى جذر المستودع، مع استبدال الملفين الحاليين فقط.
3. ارفع التعديل وانتظر اكتمال نشر GitHub Pages، ثم افتح الموقع وأعد تحميله.

حدود الويب:
موقع الويب لا يستطيع تشغيل GPS أو إجبار أندرويد على إظهار نافذة إعدادات النظام. إذا كان الإذن لأول مرة أو بحالة سؤال، سيطلب المتصفح الإذن عند ضغط الزر. إذا كان الإذن محظورًا، يجب تغييره من إعدادات الموقع في المتصفح ثم المحاولة مجددًا.
