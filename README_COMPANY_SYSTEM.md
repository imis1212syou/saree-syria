# سعرلي سوريا — نظام الشركات الكامل

تم دمج نظام الشركات داخل المشروع الأساسي بدون حذف نظام المتاجر.

## الموجود
- قسم مستقل في الشريط: الرئيسية، السلة، المفضلة، الشركات، المتاجر، التصنيفات.
- صفحة عامة للشركات مع البحث والتصنيفات.
- صفحة مستقلة لكل شركة.
- منتجات شركة مستقلة عن منتجات المتجر.
- السعر اختياري بالكامل؛ المنتج بدون سعر يبقى ظاهرًا.
- باركود مستقل لكل مادة شركة وإمكانية البحث عنه داخل الشركة.
- مفضلة للمواد الخاصة بالشركات.
- عرض المتاجر المرتبطة بالشركة وواتساب الشركة.
- حساب شركة جديد.
- طلب ربط حساب الشركة يظهر للمدير.
- المدير يربط الحساب بالشركة ويمنحه الصلاحيات.
- صلاحيات: إدارة المنتجات، تعديل، حذف، تصنيفات، إعدادات، طلبات.
- زر «الدعم والتواصل» موجود بدون تفعيل وظيفي.
- إدارة روابط الموقع والداعمين تبقى داخل لوحة الإدارة الحالية، مع زر وصول مباشر.

## قاعدة البيانات
للتجهيز الكامل في Supabase شغّل:

`supabase_full.sql`

وهذا الملف يحتوي على `supabase_fix.sql` ثم نظام الشركات الكامل.

يمكن أيضًا تشغيل `company_system.sql` بعد `supabase_fix.sql` إذا أردت تطبيق إضافة الشركات وحدها.
