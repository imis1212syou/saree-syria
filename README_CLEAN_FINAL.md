# سعرلي سوريا — النسخة المنظفة

هذه نسخة مدمجة من المشروع الحالي.

## ما تم تنظيمه
- توحيد ملفات وظائف المتاجر على `store_features.js`.
- إزالة نسخ JavaScript المتكررة لوظائف المتاجر والصلاحيات والإشعارات.
- إزالة تحميل `ad-view.html` كسكربت.
- إزالة `site_contact.js` المكرر.
- زر تواصل واحد يُنشأ بجانب زر تحميل التطبيق.
- أفضل الداعمين يظهر تحت منطقة إعلان الصفحة الرئيسية.
- لوحة المدير تحتوي على ربط صاحب الشركة مباشرة بالبريد، اختيار الشركة، وتحديد الصلاحيات.
- صاحب الشركة محصور بالشركة المرتبطة بحسابه.
- إضافة/تعديل/حذف مواد الشركة حسب الصلاحيات.
- عرض إجمالي زيارات الشركة فقط، بدون الزوار الفريدين.
- عرض إجمالي زيارات المتاجر.
- استخدام دوال Supabase الحالية التي تم تجهيزها سابقاً: `admin_link_company_user_by_email`, `admin_set_company_permissions_v2`, `admin_list_company_users_v2`, `admin_unlink_company_user`, `company_owner_visitor_stats`, `record_company_visit`.

## ملاحظة
قاعدة Supabase الحالية تبقى كما هي؛ لا يلزم استبدال مفاتيح Supabase الموجودة في `index.html`.
